# BSG DRADIS Raptor and Defense Test

Functional test iteration dated 2026-10-01, based on the complete Status and Combat Test. This separate project copy retains the Godot name BSG DRADIS.

## Changes

- **Audio:** Stronger two-blast identification klaxon, looping battery gunfire, FTL jump effect and repeating nuclear-threat alarm.
- **Game Over:** Centered red-bordered panel with Game Over and a Retry button.
- **Battery:** Six-second maximum activation, 18-second cooldown, anti-toggle safeguards, tracers and firing/cooling button feedback.
- **Nukes:** One per Basestar, slow travel, flashing symbol, prominent warning, 60-hull impact and Raptor/FTL counterplay.
- **Raptors:** New launch button, slower craft, nuclear priority, half-strength capital missiles, return sorties, evasive movement, chance-based evasion and two-hit health.
- **Return fire:** Basestars shoot flak at Raptors; projectiles are bounded and clean up invalid targets.
- **Counters:** Explicit enemy-fighter and Viper counts, returning-Viper indicator and recovery messages.

## Preserved

The dome script and node settings, background rings, scanlines, icon geometry, ship-status outline and fill, sweep audio, contact beep, launch whoosh, hull repair, FTL percentage and existing fighter movement remain intact. Earlier working project folders are not replaced.
